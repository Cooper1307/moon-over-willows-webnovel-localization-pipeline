## 二、本章角色人设

### 申简辰 / 赵朴（男主）

| 维度 | 详情 |
|------|------|
| **真实年龄** | 前世30岁（CEO），穿越后身体18岁，年轻了12岁——他最大的惊喜 |
| **性格特征** | 具备CEO的社交能力与从容气度，能得体应对内侍。不愿贿赂，但为梦容妥协 |
| **身份认知** | 向梦容和邹嬷嬷坦白自己是申简辰，但无人相信。最终接受"认真做个不被重视的仪王" |
| **情感核心** | 心系千里寻。对梦容保持距离但尊重，被其多情眼神触动 |
| **行为逻辑** | 不受宠反而自在——"省去很多麻烦，自由自在" |

### 乔梦容 / 佳和郡主

| 维度 | 详情 |
|------|------|
| **身世背景** | 6岁被亲生父母遗弃路边，被赵朴马车救回，视赵朴为救赎与唯一依靠 |
| **情感深度** | 即使赵朴不醒也愿为其守节。比起权势，更在意赵朴的平安 |
| **处事方式** | 懂礼数、识大体。主动贿赂内侍保护赵朴，展现贤内助潜质 |
| **情感变化** | 发现"哥哥"不再含情脉脉，感到失落但选择接受。不愿承认仪王是别人 |

## 三、本章翻译挑战

1. **"Yes!" 的破次元处理**：申简辰得知年轻12岁后脱口而出的英文感叹，需保留原文以体现穿越者的现代人本质。
2. **内侍 vs 太监的视角差异**：正式场合用 "Inner Attendant"，申简辰内心独白用 "eunuch"，体现认知差异。
3. **官场潜规则的本地化**："一点心意" (a small token of appreciation) 和"美言几句" (put in a good word) 需翻译自然，让西方读者理解中国式打点文化。
4. **申简辰坦白的场景**：这段对话需要区分"申简辰视角的真实"与"梦容/邹嬷嬷视角的不可接受"，译文要体现三方认知错位。
5. **用餐氛围的转变**：从"病榻上单独喂烂饭"到"同桌共享美食"，生活细节的变化是角色重生的重要标志，动作描写应轻快愉悦。
6. **梦容的情感层次**：从"哥哥不再热情"的失落 → "愿意守节"的决绝 → "不承认你是别人"的执念，情感递进需细腻处理。
