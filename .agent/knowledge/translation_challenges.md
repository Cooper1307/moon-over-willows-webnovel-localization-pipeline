[来自 第4章] 3. **居所环境描写**：竹兰居的红木家具、花鸟图案、书卷气息，需要使用具有古典美感的词汇（Antique, Elegant, Rosewood, Scholarly atmosphere）。

[来自 第4章] 5. **法律词汇**："告到衙门"、"治罪"、"休书"，这些词汇在古代背景下的权威感应通过译文体现。

[来自 第5章]    - 翻译时需体现出林觉提出"和离"其实是一种"服软"和"双赢"的方案。
[来自 第5章] 3. **点茶过程的视觉传达**：描述茶汤"鲜白"、"泡沫细腻"、"口感绵密"，需要用到如 "Whisked tea", "Frothy texture", "Velvety mouthfeel" 等词汇。
[来自 第5章] 4. **角色语气的转变**：林觉从强硬到服软的口吻转变；千里寻在处理古代繁琐离婚手续时的心理活动（"入乡随俗"）。

[来自 第6章] 3. **失忆的文化推合**：利用"孟婆汤"解释失忆是本章的关键情节。为了让西方读者理解，需准确传达出这是一种"重获新生但代价是抹去记忆"的概念。
[来自 第6章] 4. **尊卑待遇的描写**：丫鬟蹲下穿鞋、郡主和嬷嬷闪避一旁等动作，需要细腻的动词来体现皇室的威严感。
[来自 第6章] 5. **欺君之罪的紧迫感**：下人报丧后王爷复活带来的恐惧，需要通过具体的语气和动作描写传达出那种伴君如伴虎的政治压力。
