# 网文小说翻译四阶段优化工作流

本工作流定义了从机器翻译初稿到最终交付的完整优化流程，适用于已完成初译的章节深度优化。

---

## 工作流概览

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  Phase 1    │ →  │  Phase 2    │ →  │  Phase 3    │ →  │  Phase 4    │
│  初次MTPE   │    │  再次MTPE   │    │  润色提升   │    │  商业审校   │
│  基础纠错   │    │  深度审校   │    │  语言优化   │    │  市场合规   │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

---

## Phase 1: 初次 MTPE（基础纠错）

### 目标
修正机器翻译的硬性错误，确保基础翻译质量。

### 检查清单

| 检查项 | 具体要求 |
|--------|----------|
| **漏译排查** | 逐句核对原文，补全所有缺失的译文段落、术语、标题 |
| **代词纠错** | 逐句核对 he/she/they 是否匹配正确角色性别 |
| **术语一致性** | 所有专有名词是否与术语表（`术语表/术语表_Trados_Tab.txt`）匹配 |
| **隐藏主语补全** | 中文省略的主语在英文中必须补全 |
| **诗词译本验证** | 古典诗词必须联网检索权威译本（许渊冲、Burton Watson 等），确认无名家版方可自译并标注 `[TN: Translator's rendering]` |
| **基本语法修正** | 消除错别字、病句、标点误用 |

### 1.5 去 AI 痕迹自检卡（写作时强制执行，Phase 1 必过）

> **完整模式库**：`网文小说合集/.codebuddy/.agent/skills/humanize/humanizer-en.md`（29 类）。
> **精简卡**：`.agent/skills/translation_sop.md` §三·五。
> **原则（借鉴 MTPE）**：落笔即改，**不留到 Phase 2 兜底**。

- **A 级零容忍**：AI 高频词（delve / tapestry / testament / pivotal / robust / landscape / crucial / vibrant）· -ing 尾句浅析 · 系词回避（serves as / boasts）· 宣传腔 · 卷曲引号
- **B 级计数上限**：em dash ≤2 处/章 · 三段式 ≤1 处/章 · 否定排比 0
- **C 级体裁专项**：同义词循环（术语/称谓全书一译，接受重复）· `VERB + -ly` 弱填充副词 · 情绪加戏副词（原文无对应则删）
- **优先序**：忠实原文 > 术语锁 > 去 AI 痕迹 > 表达自然
- **报告格式**：`自检卡：A 级命中 X 处（已改） / B 级 em dash X 处、三段式 X 处 / C 级 -ly 副词 X 处（已转写）`

### 输出要求
- 直接在原初译文件中修改
- 报告格式：`修正了 X 处漏译 / X 处代词错误 / X 处术语不一致 / 自检卡 A 级 X 处（已改）`

## Phase 2: 再次 MTPE（深度审校 + 外部审校意见整合）

### 目标
全面提升翻译的表达质量、地道性和可读性。整合外部 AI 审校意见，酌情采纳并修改项目文件。**必须输出前后对比**。

### 2.0 外部审校意见整合（前置步骤）

用户可能会引入外部 AI（如 Qwen、Gemini 等）生成的审校意见文件，要求参考并修改项目文件。此步骤必须在自主审校之前执行。

#### 输入
- 用户提供的审校意见文件（如 `第X章审校意见-Gemini.md`、`第X章审校意见-Qwen.md`）
- 当前章节的译文文件（`第X章初译_对照.md`、`第X章译文.md`）

#### 处理流程

**Step 1：读取与归类**
- 读取所有外部审校意见文件
- 将意见按类型归类：

| 类别 | 优先级 | 说明 |
|------|--------|------|
| 🔴 硬伤（事实错误） | 最高 | 漏译、人名拼写错误、逻辑矛盾、诗词译本错误 |
| 🟡 表达优化 | 高 | 重复用词、句式过长、不地道表达、标点格式 |
| 🟢 风格建议 | 中 | 标题优化、角色语调、感官层次增强 |
| ⚪ 主观创作 | 低 | 大幅改写、添加原文不存在的细节/情节 |

**Step 2：逐条评估与决策**

对每条外部审校意见，按以下标准判断是否采纳：

| 判断标准 | 采纳 | 不采纳 |
|----------|------|--------|
| **忠实原文** | 修改后更贴近原文含义 | 修改后偏离原文或添加原文没有的内容 |
| **术语一致性** | 与术语表一致 | 与已核验的术语/人名/诗词方案冲突 |
| **项目约束** | 符合网文风格、短句式、移动端阅读 | 过于文学化/书面化/学术化 |
| **跨章一致** | 与前几章的翻译方案保持一致 | 引入与前章矛盾的新译法 |
| **可行性** | 修改粒度合理、可操作 | 需要大规模重构且收益不大 |

**Step 3：执行修改**
- 对采纳的意见：直接在译文文件中修改
- 对不采纳或部分采纳的意见：保留原译法，在报告中说明理由

**Step 4：输出审校意见整合报告**

必须使用以下格式输出：

```markdown
## 外部审校意见整合报告

### 已采纳（X 条）

| # | 意见来源 | 问题描述 | 修改前 | 修改后 |
|---|----------|----------|--------|--------|
| 1 | Gemini | "Kubiao"拼写错误 | Kubiao | Kuqiao |
| 2 | Qwen | "said"重复12次 | said (×12) | demanded/reassured/whispered... |

### 部分采纳（X 条）

| # | 意见来源 | 意见内容 | 采纳部分 | 未采纳部分 | 理由 |
|---|----------|----------|----------|------------|------|
| 1 | Qwen | 住持独白拆分为4段 | 拆分为3段 | 未加入舞台指示 | 原文无停顿描写，添加过多 |

### 未采纳（X 条）

| # | 意见来源 | 意见内容 | 不采纳理由 |
|---|----------|----------|------------|
| 1 | Gemini | 将"醍醐灌顶"改为"Your words just... cracked something open in my head" | 过于现代化，不符合古代角色语调设定 |
| 2 | Qwen | 标题改为"The Nun in the Dark" | 原标题已在前章建立读者认知，不宜更改 |
```

> ⚠️ **关键约束**：
> - 外部审校意见仅为参考，最终决策权在项目一致性原则
> - 不得因外部意见而破坏已核验的术语表、人名方案、诗词译本
> - 不得因外部意见而添加原文不存在的细节（"加戏"）
> - 当多个外部审校来源意见冲突时，以"忠实原文 + 项目一致性"为最高裁决标准

### 审校维度（自主审校部分）

在完成外部审校意见整合后，继续执行以下自主审校：

#### 2.1 表达正确性与地道性
| 检查项 | 具体要求 |
|--------|----------|
| **中式英语排查** | 消除直译导致的生硬表达，重构为自然英语句式 |
| **动词多样性** | 避免同一动词（如 said, looked, walked）在短距离内重复，使用同义替换 |
| **副词节制** | 英文网文不喜过度使用副词修饰动词，能删则删 |
| **文化适配** | 东方玄幻元素避免西方宗教色彩（如 divine → neutral terms; blessed → fortunate） |

#### 2.2 句长控制与节奏
| 检查项 | 具体要求 |
|--------|----------|
| **长句拆分** | 超过 40 词的复合句必须拆分 |
| **碎片句运用** | 在情绪高潮点使用碎片句（如 "Silence." "She froze."）增强节奏感 |
| **段落控制** | 单段不超过 150 词，长独白需拆分为多段并加入停顿描写 |

#### 2.3 标点与网文格式
| 检查项 | 具体要求 |
|--------|----------|
| **内心独白** | 统一用 *斜体*，不用引号 |
| **对话标签** | 仅在原文有明确情绪信号时补充（sneered / murmured 等），严禁主动推断情绪 |
| **感叹号使用** | 网文允许适度使用感叹号增强情绪，但不可过度 |

#### 2.4 重复用词排查
**必须执行全文扫描，对高频重复词汇进行同义替换**

常见重复词及替换方案：
| 原词 | 出现次数阈值 | 替换方案 |
|------|-------------|----------|
| said | >3次/章 | demanded / reassured / whispered / snapped / remarked / chuckled |
| cave | >6次/章 | the space / inside / the dark / the chamber / the grotto |
| dark/darkness | >8次/章 | blackness / gloom / shadow / the void |
| immediately | >2次/章 | at once / instantly / right away / 直接删除 |
| very/quite | >3次/章 | 删除或重构句子 |

#### 2.5 章节级重复表达与副词修饰动词专项排查（Phase 2 收尾必做）

作为 Phase 2 自主审校的**最后一步**，必须在本章范围内专门排查以下两类问题，确认无误后方可进入 Phase 3：

**A. 章节级 + 跨章节重复表达与句式排查（避免表达单调乏味）**
- 对本章全文逐句扫描，重点识别：
  - 同一句或相邻句内重复的词/短语（如同一句出现两次 `inside`、两次 `give`）
  - 同一概念在短距离内用不同句式重复表述（如「很快不是你的 / 很快不是我的」句式不一致）
  - 对话/独白中缺宾语或指代不清的重复结构
- **跨章节重复排查（串联全系列）**：
  - 抽取本章高频表达、惯用句式、固定搭配（如情绪描写 `a sense of warmth welled up`、动作链 `went out and said`、评价句 `couldn't be happier for you`），与已定稿的邻近章节（建议查前 2–3 章及同卷章节）比对，避免同一短语/句式在多章反复出现、造成全系列表达单调。
  - 对跨章高频的"万能句"（如反复使用的 `snapped`/`scoffed`/`Beaming, X said` 套式）做轮换：在同一情绪下换用同义标签或重组句式，保持人物情绪一致但措辞有变化。
  - 跨章人名/称谓/术语的拼写与格式必须一致（如 `Young Miss`、`Kuqiao`、`the bamboo forest`），此处只查一致性、不查"重复"，属忠实必要。
- **句式单调性排查**：
  - 检查连续段落是否过多使用相同主干（如连续多段 `[主语] + said + 逗号 + 引语`、`[主语] + 动词 + and + 动词` 链式并列），在不改原意前提下调整句长、语态或主从结构，提升节奏感与可读性。
  - 对反复出现的 "There was / It was" 弱存在句、"so…that" 套式做精简或重构。
- 排查方法：提取本章所有英文句，比对近邻句的用词与句式；跨章部分用 grep 在 `章节原文/` 下对已定稿章节检索本章惯用表达的出现频次。
- 判定原则：忠实原文 > 术语锁 > 跨章一致 > 表达自然；凡原文确有重复（如角色口头禅式重复，对应老娘的 `this queen`）须保留。跨章"轮换"只针对可替换的修辞层，不触术语与称谓锁。

**B. 副词修饰动词排查（英文风格红线）**
- 英文网文不喜用 `-ly` 副词直接修饰动词（如 `looked kindly` / `scratched his head shyly` / `let … off easily`）。
- 必须全文扫描 `VERB + -ly adverb` 组合，将弱填充副词转写为：形容词作系动词补语（`kindly` → `kind`）、分词/介词结构（`shyly` → `, bashful`）、习语（`easily` → `off scot-free`），或直接删去重构。
- 例外（保留）：`-ly` 修饰形容词或全句（如 `well pleased`、`truly honest`），以及承载原文实义的内容副词（如 `miraculously` 对应"神奇般地"），不属于本项排查范围。

> ✅ 完成上述两项排查并修正后，方可进入 Phase 3 润色提升。

### 输出要求（前后对比格式）

**必须使用以下格式报告修改：**

```markdown
### 修改点 X：[问题类型]

**修改前：**
> [原文引用]
> [原译文]

**修改后：**
> [修改后译文]

**修改理由：**
[简要说明修改依据]
```

## Phase 3: 润色提升（忠实原文基础上的语言优化）

### 目标
在**严格忠实原文**的前提下，提升语言质量和读者吸引力。

### 核心原则

> ⚠️ **红线**：不得添加原文不存在的动作、心理描写或情节细节。所有润色必须基于原文已有的内容进行语言层面的优化。

### 润色维度

#### 3.1 感官层次增强
在原文有感官描写的地方，增强英文的画面感和沉浸感：
- **视觉**：用具体名词替代抽象描述（如 "a butterfly" → "a butterfly—enormous, impossibly blue, edged in velvet black"）
- **听觉**：补充环境音效（如衣料摩擦、脚步声、呼吸声）
- **触觉**：强化质感描写（如 "cold stone" → "stone cold enough to bite through silk"）

#### 3.2 角色声音校准
| 角色 | 语调要求 |
|------|----------|
| **千里寻（女主）** | 现代感、直率、爱吐槽；内心独白用 *斜体*，语言更现代化 |
| **古代角色** | 正式、典雅；避免现代俚语 |
| **净光法师** | 禅意、睿智、有幽默感；说话有节奏和停顿 |

#### 3.3 情绪高潮点强化
在原文情绪爆发点（如"打脸"、"真相揭露"、"情感告白"），允许：
- 使用碎片句增强冲击力
- 调整句式节奏（短句→长句→短句）
- 强化动词选择（但不得添加原文没有的动作）

### 禁止操作
- ❌ 添加原文不存在的动作连缀或微表情
- ❌ 凭空捏造心理判定或情绪夸大
- ❌ 使用极端修饰词（sharply, violently, furiously）除非原文有对应
- ❌ 更改已核验的术语、人名、诗词翻译方案

## Phase 4: 商业审校（用词吸引力与平台合规）

### 目标
确保译文具备商业吸引力，符合主流平台审核要求。

### 4.1 商业吸引力审校

#### 标题优化
| 检查项 | 具体要求 |
|--------|----------|
| **画面感** | 标题应有具体意象，避免抽象概念（如 "Discussing Fate" → "The Nun in the Dark"） |
| **悬念感** | 标题应引发好奇心，暗示冲突或转折 |
| **长度控制** | 英文标题建议 3-6 个词 |

#### 开篇吸引力
| 检查项 | 具体要求 |
|--------|----------|
| **首句钩子** | 章节首句应有悬念或冲突，避免平铺直叙 |
| **场景建立** | 前 100 词内必须建立时间、地点、人物关系 |

#### 节奏控制
| 检查项 | 具体要求 |
|--------|----------|
| **爽点密度** | 每 1000-1500 词应有一个情绪高潮点（打脸、反转、揭秘） |
| **段落留白** | 关键转折后单独成段，增强视觉冲击 |

### 4.2 平台合规审校

#### 敏感词规避
| 类别 | 规避策略 |
|------|----------|
| **宗教敏感** | 避免直接翻译宗教仪式细节，可用 "ritual" "ceremony" 等中性词 |
| **暴力描写** | 避免过度血腥描写，可用 "blood" → "crimson" 等文学化处理 |
| **色情内容** | 避免 explicit 描写，亲密场景用暗示性语言（"they became one" "the night was long"） |
| **政治敏感** | 避免涉及现实政治的表述，历史背景用模糊化处理 |

#### 文化适配
| 检查项 | 具体要求 |
|--------|----------|
| **东方玄幻** | 避免西方宗教色彩（divine → sacred; blessed → fortunate） |
| **性别表达** | 符合目标市场的主流价值观，避免刻板印象 |
| **历史称谓** | 保持文化特色但确保可读性（如 "Your Highness" 可简化为 "My Lord" 视语境而定） |

### 输出要求
- 生成《商业审校报告》，包含：
  - 标题优化建议（如有）
  - 敏感词处理清单
  - 文化适配调整说明
  - 平台合规风险评估

## 执行约束

1. **忠实原文优先**：所有润色必须在忠实原文的基础上进行，不得添加原文不存在的细节
2. **前后对比必须**：Phase 2 和 Phase 3 的修改必须输出前后对比
3. **术语一致性**：任何阶段不得更改已核验的术语、人名、诗词翻译方案
4. **段落校验**：每个阶段输出时必须报告段落数一致性
5. **文件同步**：修改必须同时更新 `第X章初译_对照.md` 和 `第X章译文.md`

## 快速检查清单

完成全部四个阶段后，确认以下项目：

- [ ] 无漏译、无代词错误
- [ ] 术语与术语表完全一致
- [ ] 诗词使用权威译本或已标注
- [ ] 无高频重复用词（said/cave/dark 等已替换）
- [ ] 章节级重复表达已排查（同句/近邻重复、句式不一致已修正）
- [ ] 跨章节重复表达已排查（与邻近章节比对，惯用短语/句式已轮换，避免全系列单调）
