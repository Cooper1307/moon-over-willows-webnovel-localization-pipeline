## 一、项目是什么

中文网文《月上柳梢头，人约黄昏后》的英文本地化项目。题材：宋代古装穿越（现代人魂穿体弱皇子）。目标读者为海外网文平台读者，翻译策略为**异域保留**（音译人名、保留中式单位与称谓等级感），与短剧 MTPE 的"完全西化"相反。

## 四、工作流（五阶段）

1. **术语提取与注入** → 每章 `术语与人设.md` → `glossary.md` 权威主表
2. **初译**（对照版就地插入英文，写作时自检去 AI 痕迹）
3. **审校**（内部 + 外部 Gemini/Qwen，意见"采纳/部分/未采纳 + 理由"）
4. **商业审校**（标题钩子 / 爽点 / 合规四类扫描）
5. **沉淀**（anchors / TM / glossary 增量 → 重导 Trados → 批次交接文档）

核心机制：**对照版是唯一真源，纯英版由 `tools/sync_bilingual.py` 生成**；门禁 G1-G12 定义见 `工程化改造方案_借鉴剧本MTPE.md`。

## 五、红线（违反即事故）

- 中文原文零改动（MD5 基线已建，`项目文档/原文MD5基线.json`）。
- 对照版中文行与原文逐字一致（⚠ 现存在 Q11 半角标点差异，待裁定，见 TODO）。
- 术语一个词条一个定译；定译终裁权在用户；变更必须回溯已产出章节。
- 翻译质量优先级：忠实原文 > 术语锁 > 跨章一致 > 表达自然。
- 禁止 -ly 副词修饰动词（英文润色专项规则）。

## 六、给新会话的开工提示

1. 先读 `_记忆索引.md`（入口）。

3. 进度改动用脚本刷新基线，不手写统计。
4. 详见 `_占位符清单.md` 待用户确认项。
