# 核查触发清单（web-verify 参考）

## 一、触发矩阵（细化）

| 类别 | 命中即强制联网 | 本项目常见实例 |
|---|---|---|
| A 敏感 | 现当代政治机构/人物、领土与地名争议、宗教民族表述、{{其它敏感类目}} | 现代国名与地区称谓 |
| B 真实性 | 人名、朝代官制与封号、典故与引文出处、统计数据、作品/作者信息 | 官职名（如{{官制例}}）、器物名、诗词出处 |
| C 时效性 | 近 3 年流行语与新词、平台政策与费率、版权与授权、货币度量、发布规则 | 网文平台稿酬/更新规则、网络用语 |
| D 平台规范 | 目标发布站的投稿/分级/敏感词/封面与简介规范 | {{平台}}分级标准 |
| E 资料检索 | 论文、行业报告、官方文档 | 本地化/翻译学论文 |

## 二、检索式写法

- **中文词**：专有名词原文 + 定性词（"是什么/出处/对应英文"）。
- **英文词**：已有候选译名 + `meaning / origin / official`，用于反查英文世界通行的接受度。
- **限定**：加年份或 `site:` 提高时效性与权威性；学术资料加 `DOI / PDF / 期刊名`。
- **双语交叉**：中文确认"是什么"，英文确认"英文读者怎么称它"，两者缺一不可（避免译名自造）。

## 三、来源可信度分级

| 级别 | 类型 | 用法 |
|---|---|---|
| S | 官方一手（政府/机构/平台官方页、出版方、DOI 原文） | 可直接定论 |
| A | 权威媒体、学术出版物、行业白皮书 | 可与 S 互证后定论 |
| B | 维基/百科、 reputable 社区、二手报道 | 仅作旁证，需再配 1 源 |
| C | 论坛、自媒体、AI 生成内容 | **不作定论依据**，最多提供线索 |

**规则**：结论至少需要 2 个独立来源，且不全为 B/C 级。

## 四、冲突与缺口处理

- 来源冲突 → 并列列出，标 `[待人工裁定]`，说明各自立场与时间。
- 全部搜不到 → 记"未获证实"+ 已试检索词，交用户决定是否沿用内知假设。
- 来源过期（>12 个月且属 C 类）→ 重搜，注明"时效性存疑"。
