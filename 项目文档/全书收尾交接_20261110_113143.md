## 四、续跑指令（复制粘贴即可，批次间不要插入审批）

```
1. python tools/session_check.py --start --apply
2. 为待译章产出逐段英文行文件：
     项目文档/待译英文行/ch<N>_en.txt
   格式：可选首行 `#TITLE: <英文题名>`；之后每行一段英文，行数 = 该章原文正文段数。
   **中文行不用写**，compose_bilingual.py 会从 第N章原文.md 逐字重取。
   术语先跑 python tools/glossary_slice.py --chapter N；诗词/典籍先跑 skill poem_web_verify。
   单章段落数自查：python tools/run_batch.py（dry-run 会打印每章对齐状态）。
3. python tools/run_batch.py --apply                # 连续处理；失败章留存自动重试
4. python tools/session_check.py --end --apply      # 每批收尾闸门
5. 回到 2，直到 项目文档/全书翻译台账.json 的 待译章 = []
6. 存量 87 章 P0/P1 清零：逐条裁定 → 改对照版英文段 → docx 修订闭环
   (docx_revision.py --author CooperChen → verify_revision_docx.py → scrub_docx_meta.py --apply)
   → 回填真源 → extract_pure_en.py 重派生
7. python tools/build_delivery_docx.py --batch 1-351 --apply
   python tools/scrub_docx_meta.py --dir 交付版 --apply
8. 三层复验（章级 / 批级 / 全书级）每轮全绿；
   python tools/lqa_gates.py --chapter 1-351 --fail-on P1 退出码必须为 0
9. python tools/session_check.py --end --apply 的 E2b = PASS 才允许停止
```

**逐章验收样板**：第1章（`章节原文/第1章/第1章初译_对照.md`）。
**注意**：`extract_pure_en.py --chapter` 的逗号列表会被 `parse_range` 当成 min/max 区间，必须逐章单章调用；`run_batch.py` 已按单章处理，不要绕过它。
