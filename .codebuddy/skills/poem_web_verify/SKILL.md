# 诗词典籍联网核验与二创（poem_web_verify）

> 原则：**先查现成，再谈二创**。诗词是「已有成品」的文化资产——英美汉学界已有大量成熟译本，能引则引（标出处），不得凭空硬译或自造句式。

## 一、何时必须触发

| 情形 | 判定 |
|---|---|
| 词条属真实存在的诗词/曲牌/典籍/书名/篇名 | 必须联网 |
| 译文引用了诗句原文、典故出处、典籍原句 | 必须联网 |
| 词条在 glossary 第六节「诗词与典故」 | 必须联网（该节即高风险清单） |
| 自造的角色诗词、口号、偈语 | 不强制（但要避免与真实作品撞名） |

> 附加触发：译文里出现「作品名 + 作者 + 朝代」的组合，或出现 `*Xun* (尋)` 这类汉字注释，同样先核验该作品的标准英译名。

## 二、六步 SOP

1. **锁定作品身份**：作者、朝代、篇名、是否为词牌/曲牌（词牌是格律名，不是作品名，处理方式不同）。先在 glossary 第六节与章节原文里确认到底引用了哪一首。
2. **内知先提假设**：写下"我印象中的通行英译是 X（置信度 高/中/低）"，作为待验假设。
3. **联网检索**：中英双语各跑一次，**≥2 个相互独立来源**；优先学术译本与权威数据库。常用检索式：
   - `<作者拼音/英文名> "<篇名拼音>" English translation <关键句>`
   - `Burton Watson / Xu Yuanchong / Lin Yutang / Legge / David Hinton / Liu Wu-chi <篇名>`
   - 权威库：`chinesepoetrytranslation.org`、`ctext.org`、Wikipedia 作品条目
4. **交叉验证**：一致 → 采纳；冲突 → 并列记录并标 `[待人工裁定]`；**禁止用"我认为"压过来源**。
5. **落记录**：结论写入 `项目文档/诗词核验记录_YYYYMMDD.md`（含作品、来源 URL + 抓取日期、现成译本原文片段、采纳/二创理由）。
6. **回报与处置**：只给"结论 + 来源 + 对译文的影响"，**不擅自改译文与术语定译**；是否统一、采用哪个译名由用户裁定。

## 三、常见学术译本对照（检索起点，非结论）

| 译者 | 特点 | 典型篇名写法 |
|---|---|---|
| Burton Watson | 汉语学界公认权威，忠实而自然 | *Mid-Autumn Festival — To the Tune of Shuidiaogetou*；*Bamboo Grove Pavilion* |
| 许渊冲 Xu Yuanchong | 韵文为主，传达情致 | *Immortals at the Magpie Bridge* |
| 林语堂 Lin Yutang | 散文体，重意境 | *Prelude to the Water Melody* |
| 理雅各 Legge | 逐字直译，学术标准 | *The peach tree is young and elegant…* |
| David Hinton | 简洁现代 | *Bamboo-Mist Cottage* |
| 刘伍季 Liu Wu-chi | 早年经典英译 | *Bamboo Lodge* / *Bamboo Adobe* |

> 同一部作品常有 3–5 个并行英译名，**这是正常现象**。本项目的口径：**篇名与诗句正文分开处理**——篇名可择通行其一，诗句正文原则上保留一位译者的完整版本并标注出处。

## 四、词牌 vs 作品名（易错）
- **词牌/曲牌**（《水调歌头》《浣溪沙》《鹧鸪天》）：是格律名，本身无固定内容。常译 *to the tune of X*、*Water Melody*、*Huanxisha*，或保留拼音。**不要**当成具体一首诗去"核对译文"。
- **具体作品**（《桃夭》《竹里馆》《鹊桥仙·七夕》《江城子·赏春》）：有确定作者与原文，可核对具体译本。
- 定译时优先**保留拼音 + 括注通行英译**（如 *Shuidiao Getou* (Water Melody)），避免海外读者检索不到。

## 五、二创规则（在现成样本基础上改写）
1. **能引则引**：已有通行译本且语义与本书语境相符 → 直接采用并标注译者出处。
2. **需二创**：仅在①语境与原作差异大、②书中有角色化改写、③译者要求避免直引的情况下才改写。
3. **最小改动**：保留原译的意象与句序，只调整人称、时态、礼称与叙事人称适配；**不得自由发挥改写意象**。
4. **诗句是角色台词时**：以口语化可读性为先，允许拆行长句，但保留原词数节奏感与关键意象。
5. **字谜/灯谜类**（如《断肠谜》）：按 `translate_chapter.md` 标 `[PUZZLE]`，暂停 AI 自动翻译交人工。

## 六、落地一致性检查（自动化）
译文的实际译法可能与 glossary 定译不一致，**术语与正文要分开查**。用工具核对，不要靠记忆：
```
python tools/check_poem_terms.py            # 全量对表（默认只报告）
python tools/check_poem_terms.py --section 6 # 只查第六节诗词与典故
python tools/check_poem_terms.py --apply     # 把报告写入 项目文档/诗词术语落地核对_*.md
```
输出三类问题：①定译与译文实际译法不一致；②已译章内该词条完全未落地；③同一中文术语在译文中出现多种译法（AI 痕迹）。

## 七、红线

- **终裁权在用户**：核验结论一律 `[建议]`，改不改、改成哪个由用户裁定（与 glossary 术语终裁规则一致）。
- **不确定就写不确定**：搜不到 → 写"未获证实"，并列已试检索词。
- **引用可追溯**：每条结论带 URL + 抓取日期；付费墙/失效来源须注明。
- **既有红线照旧**：中文原文零改动；对照版是唯一真源；译文为派生物（`tools/sync_bilingual.py`）。**核查不得成为改中文原文的理由**。
- **禁止杜撰出处**：不得编造译者、篇名、书名或"据说"的译本。
- **一词一译**：确认为通行译名后，须回溯已产出章节统一，禁止只改表不改稿。

## 八、本项目适配（第二本小说 · 古装穿越 · 异域保留）
- 本项目**异域保留**（与 MTPE 的完全西化相反）：文化专名保留或音译，**不因"西方读者看不懂"就替换掉诗词典籍**。
- 因此本 skill 的作用是**提高准确度与可检索性**，不是**替换文化专名**。海外读者看不懂时，优先补脚注（TN）或保留拼音+括注，而非替换作品。
- 作品名译名一经用户裁定，立即回写 `glossary.md` 第六节并用 `tools/check_poem_terms.py` 复跑，确认已译章全部统一。
