# 古装题材专项规则（Novel Rules）

> 题材 = 宋代古装穿越（现代人魂穿体弱皇子）。目标读者要"异域感"。
> ⚠️ **与短剧 MTPE 相反**：禁止"完全西化"（置换美式地名/机构/币制）；本项目的西化属红线。具体分级见下方"本地化分级表"。

## 一、本地化分级表（异域保留分级，替代 MTPE 的 A~E 西化）

> 完整正反例表见 `工程化改造方案_借鉴剧本MTPE.md` §3.5；此处为执行摘要。

| 档 | 类型 | 策略 |
|---|---|---|
| 甲 人名地名 | 角色/府邸/地名 | 音译保留 + 通用词意译（朱府=Zhu Manor） |
| 乙 官制称谓 | 官职/皇室/亲属 | 功能对等 + 保留等级感（官家=His Majesty；嬷嬷=Matron） |
| 丙 文化专有项 | 器物/饮食/服饰/习俗 | 首现内嵌解释，后续直用，不过度 `[TN:]` |
| 丁 宗教哲学 | 佛道/命理/占卜 | 去西方宗教色彩（divine→deity；居士=Jushi 音译） |
| 戊 古典诗词 | 诗词/典故 | 名家译本优先 + 标 `[TN: Translated by …]` |
| 己 现代梗 | 穿越女主现代词汇 | 保留现代口语与古语域反差（这是卖点） |
| 庚 度量货币 | 银两/里程 | 保留中式单位（fifty taels of silver），不换算 |

## 二、题材红线

- 中文对白引号用中文“”（归一化后统一全角）。
- 角色音色分层（女主 sassy / 男主 composed / 女配 meek）见 `.agent/knowledge/characters/`。
- 人物异写归一：{{文渊/文轩 = 乔文仙（Wenxian），后续章遇则归一}}。
- {{待细化：本表可由用户按需扩展，如专属文化项清单}}

## 三、本地工程注意（古装特有）

- 对照中文化用词与原文逐字一致；人名/官衔高频重复必要，不禁重复。
- 术语候选自动归类存在误差（如通称归入角色名）→ 人工裁定时顺手调整，勿自动改 glossary 分类。
